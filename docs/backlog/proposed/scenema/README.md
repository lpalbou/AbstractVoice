## Proposed Scenema track

This folder groups the proposal set created from the Scenema evaluation.

Important scope note:

- `046_scenema_class_python_runtime_spike.md` is the Scenema-class runtime item.
- `044`, `045`, `047`, and `048` are broader prerequisite architecture items
  that remain useful beyond Scenema.

Recommended promotion order:

1. `044_package_owned_directed_speech_request_and_capabilities.md`
2. `048_abstractvoice_owned_speech_planning_boundary.md`
3. `045_shared_runtime_foundation_for_advanced_speech_engines.md`
4. `046_scenema_class_python_runtime_spike.md`
5. `047_device_agnostic_runtime_and_apple_silicon_path.md`

Why this folder exists:

- keep the Scenema-originated proposal set readable as one track;
- avoid spreading closely related architecture notes across the top-level
  `proposed/` directory;
- make it explicit that not every item in the track is Scenema-only.
