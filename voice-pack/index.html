    Built-in voices¶

    AbstractVoice ships 70 ready-made voices for Qwen3-TTS: women and men in American and British English, French, Spanish, German and Italian, including a deep, professional bass male voice in every language. They behave like voices you cloned yourself (same ids, same calls, same listings), are available offline once the model is cached, and are read-only.

    This page covers what you need to use them, the full list, and how they were made. For cloning your own voices see API: voice cloning; for licensing see Voices and licenses.

    Requirements¶

    • pip install "abstractvoice[qwen3-tts]" (Python 3.10+; on Apple silicon it runs on the Apple GPU through MLX, elsewhere on PyTorch).
    • The Qwen/Qwen3-TTS-12Hz-1.7B-Base checkpoint, which renders every built-in voice: python -m abstractvoice download --qwen3-tts Qwen/Qwen3-TTS-12Hz-1.7B-Base (or allow downloads and let the first use fetch it).

    The package itself only carries each voice's clone prompt (its reference codec codes and speaker embedding, about 12 KB per voice); no reference audio is shipped.

    Use them¶

    The voice id is all you need. Any voice can read any of the ten Qwen3-TTS languages; it sounds most natural in its own.

    from abstractvoice import VoiceManager

vm = VoiceManager(cloning_engine="qwen3-tts")
wav = vm.speak_to_bytes("Bonjour et bienvenue.", voice="fr-female-camille")
vm.speak_to_file("Good evening.", "news.wav", voice="en-gb-male-oliver", one_shot=True)
for chunk, sr in vm.speak_to_audio_chunks("A longer reply, streamed as it is generated.", voice="en-us-male-harrison"):
    ...
vm.speak("Hallo zusammen!", voice="de-female-anna")
[v["voice_id"] for v in vm.list_cloned_voices() if v["meta"].get("builtin")]

    one_shot=True renders a whole text as one generation, so a take keeps one voice from start to end (see API: TTS).

    Command line and REPL:

    abstractvoice --prompt "Bonjour et bienvenue." --voice fr-female-camille --output camille.wav --one-shot
abstractvoice                 # then: /voices clones   and   /voices clone fr-female-camille

    AbstractCore (the voice capability plugin) lists them with your own clones and speaks with them by id:

    llm.voice.voice_catalog(provider="qwen3-tts")["cloned_voices"]  # built-in voices: tags["builtin"] is True
llm.voice.tts("Gracias por esperar.", voice="es-female-lucia", one_shot=True)
llm.voice.load_resident_model({"task": "tts", "provider": "cloned", "model": "qwen3-tts",
                               "options": {"voice": "it-male-vittorio"}})   # warm it at load

    Over HTTP, AbstractCore Server lists them in GET /v1/audio/voices and accepts the id as voice in POST /v1/audio/speech.

    Each voice carries its profile: builtin, nationality, language, language_code, sex, style (standard or bass), description and model_id. VoiceManager.list_cloned_voices() returns them under meta; the AbstractCore plugin's catalog entries (voice_catalog(), list_cloned_voices(), GET /v1/audio/voices) also expose them in tags, so clients can filter by language, sex or style.

    Built-in voices are read-only: renaming, editing the transcript, exporting or deleting one raises ValueError. A clone of your own with the same id takes precedence over the built-in voice.

    How they were made¶

    1. Designed. Each voice was described in words to the Qwen3-TTS 1.7B VoiceDesign model (the descriptions above), in the target language, stating the voice's gender explicitly.
    2. One generation, settled. Each reference was rendered with one_shot=True as a short warm-up sentence followed by the reference text. VoiceDesign settles into its voice over the first seconds of a generation, so the warm-up was cut off at the pause before the reference text, located with Whisper word timestamps.
    3. Checked. Of three takes, only those transcribed in the right language with at most 9 % word errors were kept, and the steadiest one (speaker-embedding similarity of every 2.5 s window to the clip's average voice) was chosen. Gender was cross-checked by pitch and a speaker-embedding vote.
    4. Listened to. Every voice was accepted by ear before it was cloned.
    5. Cloned. tools/voice_pack/build.py encoded each reference once with the 1.7B Base checkpoint (PyTorch reference implementation) and stored the clone prompt in abstractvoice/assets/voices/qwen3_tts/ (voices.json and prompts/<voice-id>.npz).
    6. Verified. Every voice then spoke a new sentence in its language through the AbstractCore plugin, loaded from the pack alone, and was checked for words, language and likeness to its reference.

    To add or rebuild voices, put validated references and a profiles.json (id, file, name, nationality, language, language_code, sex, style, description, reference_text) in a folder and run python tools/voice_pack/build.py <folder> from a repository checkout.
